# 千瓜数据（qian-gua.com）站点总览

## 基本事实

- **唯一可用域名是 `qian-gua.com`**（app.qian-gua.com 为控制台）。`qiangua.com` 已死（连接直接被重置），不要尝试。
- 登录一次后登录态跨会话保持（尊享版 Pro 实测）；Ego Lite 升级会清空 TaskSpace 但**不清登录态**。
- 账号体系：主账号下有子账号（子账号），导出额度按主账号池计算。

## 关键页面

| 页面 | URL 片段 | 用途 |
|---|---|---|
| 笔记搜索 | `/#/material/note/<关键词>` | 精品笔记池主入口 |
| 笔记评论搜索 | 同页 tab「按笔记评论搜索」 | 逐条评论原文 |
| 数据导出中心 | `/#/monitor/keywordExport/home` | 「数据导出中心 / 数据导出历史 / PDF导出历史」三个 tab |
| 报告下载 | 数据导出历史 tab | 异步报告完成后从行内「下载」按钮取 Excel |

## 数据获取三通道（优先级从高到低）

1. **平台原生导出**：「生成笔记数据报告」弹窗（列表页右上「导出」按钮）→ 选「导出前 N 条」→ 异步生成（2-10 分钟，实测更快）→ 数据导出历史下载。Top1000×27 列含笔记链接/互动指标/达人画像/热搜词Top10/评论热词Top10。**消耗导出额度（每条数据 1 条额度）**。
2. **AI 解析笔记**：列表页 `div.select-ai-note-btn` → 滚动加载 ≤100 篇 → 表头全选 → 「开始解析」（1 次/400）→ 内置 AI 可提 20 问/每次解析。AI 可引用评论样本但拿不到原文。
3. **页面直接抓取**：仅当上面两通道不可用时用，注意防风控（随机间隔）。

## 额度模型（2026-10 实测）

- 导出额度：全部数据导出按笔记数计（如 7,489 条=7,489 额度）；「导出前 N 条」只扣 N。
- 解析次数：400 次/周期，每次「开始解析」扣 1，选「更新数据」另扣更新次数（每篇 1 次，通常选「不更新，直接解析」）。
- 提问：每次解析 20 问；**network error 弹窗后不要盲目重发**（见 pitfalls）。
