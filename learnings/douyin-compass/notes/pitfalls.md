# 抖店罗盘页面自动化踩坑清单

## 1. 官网首页是营销页（2026-10-26）

- **现象**：直接 `goto /dashboard` 会被重定向回营销首页。
- **解法**：点右上「登录」BUTTON → 下拉「商家入口」→ 新标签 `/login?roleType=shop` 扫码。「登录」按钮是 `ecom-btn` 类的 button，文本精确匹配「登录」+ children.length===0 定位。

## 2. 登录页开在新标签（2026-10-26）

- **现象**：点商家入口后 p1 的 URL 不变。
- **解法**：监听 `[ego-browser:pages]` 提示或 `task.tabs()`，对新标签 `task.page("p2")` 接管操作。

## 3. 店透视插件会接管表格导出（2026-10-26）

- **现象**：「一键导出工具」里点「导出表格」，下载文件名带 `店透视_` 前缀。
- **根因**：店透视插件在罗盘页面也激活，拦截了导出动作。
- **影响**：文件名不可预期（不能按官方命名模式匹配），但**download 事件可捕获、内容正确**。若需官方原生命名，先在 Ego Lite 扩展管理里临时停用店透视。

## 4. 「下载明细」坐标点击前必须先取真实坐标（2026-10-26）

- 按钮在页面下方（y≈877），elementFromPoint 先行验证，防止命中浮层（一键导出弹窗残留时会挡住）。
