# 抖店罗盘（compass.jinritemai.com）站点总览

## 登录

- 官网首页 `compass.jinritemai.com` → 右上「登录」→ 下拉选**商家入口**（href: `/login?roleType=shop`）→ 新标签打开扫码页（抖店 App 扫码）
- 扫码后落在 `/shop`（商家后台主屏）。**登录态跨会话保持（2026-10-26 首登待长期验证）**
- 登录动作会开新标签页 p2（receipt.popups 或 pages 提示），后续操作用 p2

## 关键路由

| 页面 | 路由 | 内容 |
|---|---|---|
| 商家主屏 | `/shop` | 经营概况 + 右上「批量取数」入口 |
| 直播概览 | `/shop/live-overview` | 正在直播的直播间卡片（大屏入口） |
| 直播复盘 | `/shop/live-review` | **核心导出页**：账号/日期筛选 + 概览指标 + 「一键导出」「下载明细」 |

## 导出双通道（2026-10-26 实证）

1. **「一键导出」**→ 弹出「一键导出工具」，列出页面内所有数据表（每表带「复制表格/导出表格/设置」）。点「导出表格」→ download 事件**可捕获**，但文件被店透视插件接管（文件名前缀 `店透视_直播复盘_概览数据_...`）。
2. **「下载明细」**→ 直接下载 `直播复盘_渠道分析_MMDD_HHMM.xlsx`（流量趋势 sheet：整体/较上周期/各流量渠道 × 21 指标，含曝光/观看/互动/GMV/投放消耗）。

## 与 kimi-webbridge 日报流程的对应（ego 改造映射）

kimi 三件套 → ego 通道：
- 直播间明细 → 直播复盘「下载明细」（渠道分析）或场次详情页
- 商品日报 → 「一键导出工具」的商品数据表 / 首页「批量取数」
- 整场流量 → 「一键导出工具」的流量相关表

## 账号结构

- 本账号：<店铺名>（官方账号，个护家清）
- 同一抖店账号下 2 个直播间（官号+沐浴露），日报按 N-1 规则取数，周一补上周五/六/日
