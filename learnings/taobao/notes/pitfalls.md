# 淘宝/天猫 踩坑记录（append-only：现象 → 根因 → 解法 → 验证日期）

## 1. 搜索页价格被反爬掩码

- **现象**：搜索结果页的价格字段加密/部分位数掩码，页面上看起来正常但 DOM 里拿不到明文数值；店透视导出的「券后价」列同样有位数掩码。
- **根因**：淘宝对搜索页价格做反爬处理，前端按字体/加密渲染。
- **解法**：搜索页价格一律**按文本处理**，不做数值运算；要精确到手价就走详情页通道（`__ICE_APP_CONTEXT__.skuCore`）或店透视 SKU 表。
- 验证日期：2026-10

## 2. URL sort 参数不生效（假排序）

- **现象**：给搜索 URL 拼 sort 参数（如按销量排序）无效，返回仍是默认排序。
- **根因**：排序由前端交互触发，URL 参数被忽略。
- **解法**：**点击页面上的「销量」tab，并验证该 tab 处于 active 态**（有高亮 class），再取列表；否则拿到的是假排序结果。
- 验证日期：2026-10

## 3. 店透视下载捕获不到 download 事件

- **现象**：点「导出表格」/「下载全部」后，ego-browser 脚本里 `waitForEvent("download")` 一直不触发，但文件其实已经下载完成。
- **根因**：店透视走 `chrome.downloads` 后台通道，不产生页面级 download 事件。
- **解法**：**用文件系统落盘验证**：下载前记录 `~/Downloads` 快照，下载后 `ls -lt ~/Downloads` 比对新增文件；文件名有固定模式（见 overview.md 通道 1）。
- 验证日期：2026-10

## 4. 商品图 zip 文件名乱码

- **现象**：店透视「下载全部（单文件）」的 zip 解压后内部文件名乱码。
- **根因**：zip 内文件名是 GBK 编码，解压工具默认按 cp437 解。
- **解法**：解压时指定 `cp437→gbk` 转码（如 Python zipfile 预检 `filename.encode('cp437').decode('gbk')`）。
- 验证日期：2026-10

## 5. propPath 取值取错段

- **现象**：从 `skuBase.skus[].propPath` 解析规格名时得到 `-1` 这类属性 id 而非规格名。
- **根因**：`propPath` 是 `pid:vid` 用 `;` 连接，**取 vid 部分**（每段冒号后）再去 `props[].values` 里换名字；直接取第一段会拿到 pid 或无效值。
- **解法**：见 `browser-tools/extract-sku-data.js` 的 `vidName` 映射写法。
- 验证日期：2026-10

## 6. sku2info 里多出一个 "0" key

- **现象**：遍历 `skuCore.sku2info` 时多出一条 `"0"` 的数据，混进结果。
- **根因**：`"0"` 是默认/区间聚合条目，不是真实 SKU。
- **解法**：**按 `skuBase.skus[].skuId` 为准去 `sku2info` 取数，不要遍历 key**。
- 验证日期：2026-10

## 7. 售罄 SKU 没有 subPrice

- **现象**：部分 SKU 的到手价为空。
- **根因**：售罄 SKU 只有 `price`（优惠前价），没有 `subPrice`；`quantity` 可能为 0。
- **解法**：`finalPrice` 为 null 时标记「售罄/无到手价」，不要当 0 处理。
- 验证日期：2026-10

## 8. ERR_CONNECTION_CLOSED 不是风控

- **现象**：连续详情页抓取中 tmall.com 突然全部连接失败，taobao.com 正常，疑似被风控。
- **根因**：系统代理（Clash 7897）把 `tmall.com` 走了代理导致连不上；直连返回 200。
- **解法**：排查顺序**先网络后风控**——`curl --noproxy '*'` 直连目标域名确认代理规则，再考虑风控。改代理规则/直连后恢复。
- 验证日期：2026-10-29

## 9. 淘口令/短链解析不出商品 id

- **现象**：给的是淘口令或短链，正则匹配不到 `id=`。
- **根因**：淘口令需经客户端/页面跳转才能落到 `item.htm?id=`。
- **解法**：先在浏览器打开一次（或让用户先转成链接），从跳转后的最终 URL 取 `item.htm?id=`。
- 验证日期：2026-10
