## 通用反模式速查（跨站点有效）

1. Element UI 定制面板的月份标签可能无 class（取 header 最后一个 div）
2. el-table 固定列=克隆表，操作列在右列克隆行里按索引对齐
3. 下载通道两态：页面级事件可捕获 vs chrome.downloads 后台不可捕获→文件系统验证
4. Vue 受控输入用原生 setter + input 事件
5. 截图坐标 ≠ CSS 坐标，一律 getBoundingClientRect 取真实中心
6. 流式中断的僵尸状态（stop 按钮残留）→ 刷新页面恢复；提交类操作以「计数+1」为成功判据
